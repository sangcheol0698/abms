# 권한 가이드

ABMS의 권한은 **권한 코드(무엇을 할 수 있는가)** 와 **범위(scope, 어떤 데이터에 대해)** 의 조합으로 정의합니다.
권한 그룹에 (권한, 범위)를 부여하고, 계정을 하나 이상의 권한 그룹에 할당합니다.

- 권한 정의: `tb_permission` (시드 데이터, `V2__reference_data.sql`)
- 코드 상수: `kr.co.abacus.abms.access.PermissionCode`
- 범위 해석: `kr.co.abacus.abms.security.AccessService` → `DataScope`
- 권한은 **로그인 시점**에 계산되어 세션에 보관됩니다. 그룹 구성을 바꾸면 해당 사용자가 다시 로그인해야 반영됩니다.

## 1. 권한 코드

| 코드 | 이름 | 허용 기능 |
|---|---|---|
| `dashboard.read` | 대시보드/손익 조회 | 대시보드, 손익 현황, 부서·프로젝트 손익 집계 조회 |
| `employee.read` | 직원 상세 조회 | 직원 상세(연봉·직급 이력, 투입 이력) 조회 |
| `employee.write` | 직원 생성 및 변경 | 직원 등록·수정, 휴직/복직/퇴사, 승진, 연봉 변경, 삭제/복구 |
| `employee.excel.download` | 직원 목록 내보내기 | 직원 목록 CSV 다운로드 |
| `department.write` | 부서 관리 | 부서 생성·수정·삭제, 부서장 지정 |
| `party.read` | 협력사 조회 | 협력사 목록·상세 |
| `party.write` | 협력사 관리 | 협력사 등록·수정·삭제 |
| `project.read` | 프로젝트 조회 | 프로젝트 목록·상세, 매출 계획, 투입 인력 |
| `project.write` | 프로젝트 관리 | 프로젝트·매출 계획·투입 인력 생성/수정/삭제, 발행 처리 |
| `project.excel.download` | 프로젝트 목록 내보내기 | 프로젝트 목록 CSV 다운로드 |
| `summary.manage` | 손익 집계 관리 | 월 손익 재집계, 월 마감/해제, 원가 정책 관리 |
| `report.read` | 주간 보고서 | 주간 보고서 생성·조회·편집 |
| `account.manage` | 계정 관리 | 계정 발급, 비밀번호 초기화, 잠금 해제, 활성/비활성 |
| `permission.group.manage` | 권한 그룹 관리 | 권한 그룹 생성·수정·삭제, 계정 할당 |

로그인한 사용자는 권한과 무관하게 **직원 목록(디렉터리)**, **부서 조직도**, **내 정보**, **AI 어시스턴트**를 사용할 수 있습니다.
AI 어시스턴트의 조회 도구는 질문한 사용자의 권한 범위 안의 데이터만 돌려줍니다.

## 2. 범위(scope)

| 범위 | 의미 | 직원 데이터 | 프로젝트/손익 데이터 |
|---|---|---|---|
| `ALL` | 전체 | 모든 직원 | 모든 프로젝트 |
| `OWN_DEPARTMENT_TREE` | 본인 부서 + 하위 부서 | 해당 부서 소속 직원 | 해당 부서가 **주관**하는 프로젝트 |
| `OWN_DEPARTMENT` | 본인 부서 | 본인 부서 소속 직원 | 본인 부서가 주관하는 프로젝트 |
| `CURRENT_PARTICIPATION` | 현재 참여 | (해당 없음) | 오늘 기준 투입 중인 프로젝트 |
| `SELF` | 본인 | 본인 | 오늘 기준 투입 중인 프로젝트 |

- 한 권한에 여러 범위가 부여되면 **합집합**으로 적용됩니다.
- 대시보드/손익은 `dashboard.read`의 범위로 필터링됩니다. 전사 미배분 비용은 `ALL` 범위에서만 보입니다.

### `employee.write`의 범위별 동작

| 범위 | 가능 | 불가능 |
|---|---|---|
| `ALL` / 부서 범위 | 범위 안 직원의 모든 변경. 다른 부서로 이동시킬 때는 **이동 전·후 부서 모두** 범위 안이어야 함 | 범위 밖 직원 변경 |
| `SELF` | 본인 이름, 생년월일, 아바타 수정 | 그 밖의 정보 수정, 상태 변경, 등록, 삭제 |

## 3. 기본 권한 그룹

| 그룹 | 유형 | 부여 권한 |
|---|---|---|
| 일반 사용자 (id=1) | 시스템 | `employee.read`/`employee.write`: SELF, `party.read`: ALL, `project.read`/`dashboard.read`: CURRENT_PARTICIPATION |
| 최고 관리자 (id=2) | 시스템 | 모든 권한: ALL |

- 새로 발급된 계정에는 **일반 사용자** 그룹이 자동 할당됩니다.
- 시스템 그룹은 권한 구성을 바꿀 수 없고 계정 할당만 가능합니다.
- 데모 데이터에는 사용자 정의 그룹 **부서장**(부서 범위 권한 묶음)이 포함되어 있습니다.

## 4. 계정 보안

- 비밀번호는 BCrypt(`{bcrypt}` 접두사)로 저장합니다.
- 로그인 5회 연속 실패 시 계정이 잠기며, 계정 관리자가 잠금을 해제하거나 비밀번호를 초기화해야 합니다.
- 퇴사 처리된 직원과 비활성화된 계정은 로그인할 수 없습니다.
- 모든 변경 요청은 CSRF 토큰을 검사합니다. HTMX 요청은 `<body hx-headers>`로 토큰을 헤더에 담아 보냅니다.
